# KDE Breeze file icons

The 28 SVG glyphs in `src/assets/file-icons/` are copied without modification from
the installed KDE Breeze icon theme, Arch Linux package `breeze-icons 6.30.0-1`.
They remain separate SVG assets; the workspace applies presentation colors with
CSS alpha masks. No icon is downloaded or resolved from the host at runtime.

The package declares `LGPL-3.0-or-later` and `LGPL-2.1-only`. Both license texts
and the GPL 3 text referenced by LGPL 3 accompany this notice. Copyright remains
with the KDE Breeze contributors. The source theme is the KDE `breeze-icons`
project. Each original theme-relative source path and SHA-256 checksum is recorded
in `src/assets/file-icons/provenance.json`; these are the unmodified SVG sources
used to build the application.
